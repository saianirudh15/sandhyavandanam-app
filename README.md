# 🕉️ Sandhyavandanam

Sandhyavandanam is a cross-platform application that provides a step-by-step guide for performing the daily Vedic Sandhyavandanam ritual. The app offers multilingual mantra support, structured procedures, and an intuitive interface to help users perform the ritual correctly.

## ✨ Features

- 📖 Step-by-step Sandhyavandanam procedures
- 🌐 Multiple language support
   - English
   - Telugu
   - Sanskrit
   - Kannada
   - Marathi
- 🕉️ Authentic Vedic mantras
- 🎯 Daily discipline tracker
- 🌙 Light & Dark theme support
- 📱 Responsive design
- ⚡ Progressive Web App (PWA)
- 📦 Android application support using Capacitor

## 🛠️ Technologies Used

- React
- TypeScript
- Vite
- Capacitor
- HTML5
- CSS3
- Progressive Web App (PWA)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or later)
- npm
- Android Studio (optional, for Android builds)

### Installation

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

### Build the Project

```bash
npm run build
```

### Android Build

Sync the project:

```bash
npx cap sync android
```

Open Android Studio:

```bash
npx cap open android
```

Generate a signed APK or Android App Bundle (.aab) using Android Studio.
